# 游戏文化联动情报库 · 低保真线框图

> 这是一组**仅用于结构评审**的低保真线框图，灰阶占位、无视觉设计、不可点击交互。
> 目的：在进入 Figma 视觉稿之前，对齐信息架构、布局比例、模块顺序。

## 📂 文件结构

```
wireframes/
├── home.html          # 首页
├── cases.html         # 案例库列表页
├── case-detail.html   # 案例详情页
├── wireframe.css      # 共用灰阶样式
└── README.md          # 本文档
```

## 🚀 怎么打开

直接用浏览器（推荐 Chrome）打开 `home.html` 即可。三个页面之间通过顶部黑色横条的链接互相跳转。

```bash
# macOS
open wireframes/home.html

# 或者拖到浏览器
```

## 🎯 三个页面对应的用户故事

### 1. 首页 home.html
- **服务画像**：P1 立项调研者 / P2 方案借鉴者 / P3 效果评估者（全员）
- **核心任务**：分发器，让用户 3 秒内选择"看大盘 / 找案例 / 看竞品"
- **覆盖故事**：US-1.1（价值传达）/ US-1.2（近期动态）/ US-1.3（精选）/ US-1.5（厂商切入）/ US-1.6（主题切入）/ US-2.2（搜索）/ US-4.1（趋势看板）

### 2. 案例库列表页 cases.html
- **服务画像**：P2 主，P1/P3 辅
- **核心任务**：多维筛选 + 卡片墙浏览（类似 Airbnb 看房）
- **覆盖故事**：US-2.1（多维筛选）/ US-2.2（搜索）/ US-2.3（保存筛选）/ US-5.2（收藏）

### 3. 案例详情页 case-detail.html
- **服务画像**：P2 主，P1/P3 强需求
- **核心任务**：承载大量字段，分章节深度阅读
- **覆盖故事**：US-3.1（一句话结论 + 指标卡）/ US-3.2（锚点）/ US-3.3（玩法详情）/ US-3.4（商业化）/ US-3.5（舆情）/ US-3.6（文化考据）/ US-2.4（相似推荐）/ US-5.1（对比）/ US-6.2（导出 PDF）

## ✅ 已确认的设计决策（2026-06-16）

| 项 | 决定 |
|---|---|
| 案例详情页章节 | 6 个：概览 / 联动内容 / 商业化 / 舆情 / 文化考据 / 数据来源（**已删除"编辑复盘"**，无人力撰写） |

| 详情页对比模式按钮 | 顶部摘要卡右上角 |
| 详情页底部翻页 | 推荐区上方，支持键盘 ←/→ |
| 首页数据可视化 | 默认气泡图 + Tab 切换趋势图 / 矩阵热力图 |
| 首页"我关注的游戏" | 默认演示已登录态 |

## 🎨 样式约定

- **纯灰阶占位**：所有色彩仅用 `#2a2a2a / #8a8a8a / #d0d0d0` 等灰阶
- **斜纹底纹**：所有图片 / 图表区域用 45° 斜纹底表示占位
- **虚线框**：表示"可被替换/填充"的占位区
- **实线框**：表示"边界确定"的模块容器

## 🚫 这版线框图**不包含**的内容

- ❌ 视觉设计（配色、字体、品牌元素）
- ❌ 真实交互（按钮点击效果、动画、状态切换）
- ❌ 移动端适配（仅 PC 1440px 视窗）
- ❌ 完整数据（仅占位文字 + 示例数据）
